# История изменений

## [Unreleased]

### Документация

- Сокращены README и руководства по запуску.
- Исправлено описание раскраски: она подгружается некорректно. Регресс обнаружен после тестов; это уточнение документации, а не исправление в игре.

## [0.1.0-alpha.1] — 2026-09-10

Первый публичный выпуск для совместных тестов.

### Добавлено

- Лаунчер для Windows: выбор машины, подключение к серверу и запуск отдельной копии Steam-версии игры.
- Отдельный сервер для Windows и Linux.
- Передача движения и моделей машин, поворота и вращения колёс, фар, повреждений и ремонта.
- Общее время суток и погода.
- Передача гудка; проверка звучания в игре ещё не завершена.

### Известные ограничения

- Раскраска подгружается некорректно. Проблему заметили после тестов этого выпуска.
- До восьми игроков в сессии. Клиент поддерживает только проверенную Steam-версию.
- Столкновения, игровые системы, сохранение и загрузка ещё требуют доработки и проверок.
- Длительная игра через интернет и VPN недостаточно проверена; часть погодных эффектов не синхронизируется.
- Файлы для Windows пока не подписаны, сетевой трафик не шифруется.
