Экспериментальный онлайн-режим для **Hard Truck 2 / Дальнобойщики 2: Издание второе / King of the Road**. HT2MP запускает игру в отдельной безопасной копии, соединяет игроков через небольшой сервер и показывает машины друзей в одном мире.

> [!WARNING]
> `v0.1.0-alpha.1` — предварительная версия для тестирования. В ней ещё не завершена изоляция столкновений, экономики и сохранений. Перед игрой прочитайте [известные ограничения](#известные-ограничения).

## Как запустить клиент

Нужны Windows 10 или 11 x64 и установленная Steam-версия игры. Программирование и GitHub-клиент не требуются.

1. Откройте [выпуск v0.1.0-alpha.1](https://github.com/smbdsbrain/HT2MP/releases/tag/v0.1.0-alpha.1) и скачайте `HT2MP-client-0.1.0-alpha.1-windows-x86.zip`.
2. Распакуйте архив в новую пустую папку, например `C:\Games\HT2MP`. Не распаковывайте его поверх папки игры.
3. Запустите `ht2mp-launcher.exe`.
4. Введите адрес сервера, выданный его владельцем, в формате `<IP-сервера>:28020`.
5. Вставьте токен из окна сервера, укажите имя игрока, машину и раскраску.
6. Если путь к Steam-версии не найден автоматически, нажмите «Обзор…» и выберите папку с `king.exe`.
7. Нажмите «Играть». Лаунчер сам подготовит изолированную копию и войдёт в мир.

HT2MP поддерживает только точную Steam-сборку с SHA-256 `8138aceebfd67b9ed3d8e1d209a34ded92075c5627a19dc6ccbb32fb0e4c3d36`. Неизвестная или изменённая версия завершится безопасной ошибкой до инъекции. Исходная установка игры и её сохранения не изменяются: рабочая копия создаётся в `%LOCALAPPDATA%\HT2MP\runtime`.

Windows может показать SmartScreen, а антивирус — предупредить об injector/DLL. В этом релизе нет Authenticode-подписи. Сверьте SHA-256 архива с `SHA256SUMS.txt` на странице релиза и скачивайте файлы только из этого репозитория.

## Как запустить сервер

### Windows

1. Скачайте `HT2MP-server-0.1.0-alpha.1-windows-x86_64.zip` из [выпуска v0.1.0-alpha.1](https://github.com/smbdsbrain/HT2MP/releases/tag/v0.1.0-alpha.1).
2. Распакуйте архив и дважды щёлкните `start-server.cmd`.
3. Если Windows Firewall спросит разрешение, разрешите доступ только для частных сетей.
4. В окне появятся адрес `0.0.0.0:28020` и новый случайный `token`. Передайте друзьям свой LAN- или публичный IP с портом `28020` и этот токен.
5. Не закрывайте окно сервера до окончания игры.

Для игры через интернет перенаправьте **UDP-порт 28020** на компьютер с сервером. Для игры только на этом ПК запустите `start-server.cmd 127.0.0.1:28020`.

### Linux x86_64

```bash
mkdir HT2MP-server
tar -xzf HT2MP-server-0.1.0-alpha.1-linux-x86_64.tar.gz -C HT2MP-server
cd HT2MP-server
./start-server.sh
```

Разрешите входящий UDP 28020 в firewall. Для systemd, постоянного токена и расширенных параметров используйте [руководство сервера](docs/SERVER.md).

## Что уже синхронизируется

| Возможность | Статус alpha |
| --- | --- |
| Положение, направление и плавное движение машин | Работает на точной Steam-сборке |
| Модель машины и штатная раскраска | Работает |
| Поворот передних колёс и вращение всех колёс | Работает |
| Фары, повреждения и ремонт | Работает; столкновения пока не изолированы полностью |
| Пространственный гудок | Реализован, расширенная звуковая проверка продолжается |
| Серверное время суток и погода | Работает; отдельные частицы и вспышки не синхронизируются |
| Выделенный сервер Windows/Linux | До 64 подключений на уровне протокола |

Сейчас один клиент может безопасно показать не более **7 удалённых машин**, поэтому практический предел игровой сессии — **8 человек**. Серверный предел 64 сохранён для нагрузочных тестов и будущих версий клиента.

## Известные ограничения

- удалённые машины пока нельзя считать полностью изолированными от столкновений, урона и игровых систем;
- не завершены проверки сохранения/загрузки, смены комнат, заданий, полиции и экономики;
- транспорт использует ENet/UDP без шифрования: токен ограничивает вход, но не защищает трафик от чтения;
- пользовательский GUI официально поддерживает только точную Steam-версию; GOG-порт остаётся экспериментальным;
- нет длительной публичной приёмки через интернет, VPN и разные модели машин;
- Windows-бинарники пока не подписаны Authenticode.

Подробный план развития находится в [Roadmap](docs/ROADMAP.md).

## Как это устроено

```text
king.exe ↔ ht2mp-bridge32.dll ↔ ht2mp-client ↔ ENet/UDP ↔ ht2mp-coordinator
```

Игра запускается из отдельной runtime-копии. 32-битный bridge допускает запись только после проверки полного хеша и сигнатур поддерживаемой версии. Сетевые потоки не обращаются к объектам игры напрямую; неизвестные состояния переводят bridge в безопасный режим. Подробнее — в [техническом обзоре](docs/OVERVIEW.md).

## Сборка из исходников

Нужны CMake 3.24+, Git, Visual Studio 2022 с Desktop development with C++ для Windows или C++20 compiler и Ninja для Linux.

```powershell
cmake --preset windows-x86
cmake --build --preset build-x86 --parallel
ctest --preset test-x86
cmake --build --preset package-client-windows-x86
```

Серверные команды приведены в [docs/SERVER.md](docs/SERVER.md). Зависимости ENet и MinHook загружаются по закреплённым commit SHA; их лицензии находятся в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Авторский код HT2MP распространяется по [WTFPL v2](LICENSE). Сторонние компоненты имеют собственные лицензии. HT2MP — неофициальный фанатский проект, не связанный с разработчиками, издателями или правообладателями игры.

Репозиторий и релизы не содержат `king.exe`, игровых библиотек, текстур, моделей, музыки или звуков. В клиент входит только явно обозначенный анонимизированный save-template `HT2MP.pl1`, необходимый для изолированного онлайн-профиля. Для запуска нужна законно полученная копия игры.
