# HT2MP

Онлайн-мод для **Дальнобойщиков 2 / Hard Truck 2: King of the Road**. Подключайтесь к одному серверу, выбирайте машины и катайтесь вместе по знакомой карте.

**[Скачать для Windows](https://github.com/smbdsbrain/HT2MP/releases/download/v0.1.0-alpha.1/HT2MP-client-0.1.0-alpha.1-windows-x86.zip)** · [Свой сервер](docs/SERVER.md) · [Помощь](SUPPORT.md)

Нужны **Windows 10 или 11 x64** и установленная **Steam-версия игры**. Текущий выпуск — **0.1.0-alpha.1**, ранняя версия для совместных тестов.

## Как начать играть

1. Скачайте архив по ссылке выше и распакуйте в отдельную папку, например `C:\Games\HT2MP`.
2. Откройте `ht2mp-launcher.exe`.
3. Введите адрес сервера и токен, полученные от его владельца. Токен — это код доступа; на публичном сервере он не нужен.
4. Укажите имя игрока и выберите машину.
5. Если лаунчер не нашёл игру, нажмите «Обзор…» и выберите папку с `king.exe`.
6. Нажмите «Играть» и дождитесь входа в мир.

Лаунчер создаёт отдельную копию игры для онлайна. Исходная установка и личные сохранения остаются на месте. Совместимость проверяется автоматически: если версия игры не подходит, лаунчер сообщит об этом.

Для совместной игры один из участников должен [запустить сервер](docs/SERVER.md). В текущей версии в одной сессии может быть до **8 игроков**.

## Что уже работает

- Видны машины других игроков, их движение и направление.
- Передаются поворот и вращение колёс, фары, повреждения и ремонт.
- Время суток и погода общие для всех участников.
- Есть отдельный сервер для Windows и Linux; ему не нужна установленная игра.

## Известные проблемы

- **Раскраска подгружается некорректно.** Это известный регресс, замеченный уже после тестов. Ранее в документации она ошибочно отмечалась как работающая; проблема пока не исправлена.
- Столкновения, урон, задания, полиция и экономика ещё не готовы к полноценной совместной игре. Сохранение, загрузка и переходы между локациями требуют дальнейших проверок.
- Гудок передаётся по сети, но проверка звучания в игре ещё не завершена. Некоторые погодные эффекты тоже пока различаются у игроков.
- Длительные сессии через интернет и VPN ещё недостаточно проверены.
- Лаунчер поддерживает только проверенную Steam-версию. Поддержка GOG пока экспериментальная и в этот выпуск клиента не входит.
