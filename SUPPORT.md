# Поддержка

- Вопросы по установке, настройке сети и совместной игре задавайте в [GitHub Discussions](https://github.com/smbdsbrain/HT2MP/discussions).
- Воспроизводимые ошибки оформляйте через [bug report](https://github.com/smbdsbrain/HT2MP/issues/new?template=bug_report.yml).
- Предложения по развитию обсуждайте в Discussions или через feature request.
- Уязвимости отправляйте только по инструкции из [SECURITY.md](SECURITY.md).

Перед публикацией диагностик удалите токены, публичные и локальные IP-адреса, имена игроков, абсолютные пути и другие персональные данные. Не загружайте файлы игры и личные сохранения.
