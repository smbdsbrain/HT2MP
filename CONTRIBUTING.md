# Как помочь HT2MP

Спасибо за желание помочь. Для вопросов по запуску используйте GitHub Discussions, для воспроизводимых ошибок — issue form, для изменений кода — pull request.

## Перед началом

1. Проверьте существующие Issues и Discussions.
2. Для крупного изменения сначала опишите предложение в Discussion.
3. Создайте отдельную ветку и держите pull request небольшим и тематическим.

## Сборка и тесты

Windows-клиент требует Visual Studio 2022 и Win32 preset:

```powershell
cmake --preset windows-x86
cmake --build --preset build-x86 --parallel
ctest --preset test-x86
```

Портативный Linux-сервер:

```bash
cmake --preset server-linux-x64
cmake --build --preset build-server-linux-x64 --parallel
ctest --preset test-server-linux-x64
```

Перед pull request запустите `pwsh tools/audit-public-tree.ps1` и убедитесь, что `git diff --check` не сообщает ошибок.

## Безопасность данных

- не добавляйте игровые бинарники, личные сохранения, логи, дампы, скриншоты, токены, IP-адреса частных серверов или абсолютные пути пользователя;
- используйте placeholders вместо реальных секретов;
- единственный разрешённый `.pl1` — закреплённый анонимизированный template в `apps/launcher/assets`;
- перед публикацией логов удалите имена игроков, адреса, токены и локальные пути;
- не присылайте декомпилированные игровые файлы или другие материалы, на распространение которых у вас нет прав.

Отправляя contribution, вы соглашаетесь распространять свой авторский вклад по WTFPL v2. Сторонние материалы должны сохранять собственные лицензии и attribution.
