# Сервер HT2MP

`ht2mp-coordinator` — выделенный сервер сессии HT2MP/6. Он не требует установленной игры и доступен для Windows x86_64 и Linux x86_64.

## Быстрый запуск

Релизный архив содержит `start-server.cmd` для Windows или `start-server.sh` для Linux. Скрипт слушает `0.0.0.0:28020`, создаёт новый случайный токен и печатает его в консоль. Передайте игрокам адрес сервера и токен; после остановки сервера старый токен больше не нужен.

Локальный запуск без доступа из сети:

```powershell
.\start-server.cmd 127.0.0.1:28020
```

```bash
./start-server.sh 127.0.0.1:28020
```

## Ручной запуск

Публичный сервер без контроля входа:

```bash
bin/ht2mp-coordinator --listen 0.0.0.0:28020 \
  --profile steam-8138acee --public
```

Приватный сервер с токеном из защищённого файла:

```bash
bin/ht2mp-coordinator --listen 0.0.0.0:28020 \
  --profile steam-8138acee --token-file /etc/ht2mp/token
```

Файл должен содержать ровно 32 шестнадцатеричных символа и быть доступен только сервисному пользователю. `--public`, `--token` и `--token-file` взаимоисключающие. Если не передать ни один режим, coordinator генерирует временный токен и печатает его один раз при запуске. Явно заданные токены не печатаются.

Дополнительные параметры:

```text
--start-hour <0..24>
--day-seconds <seconds>
--weather-seconds <seconds>
--weather-bias <0..1>
--weather-preset <0..7>
```

## Сеть и безопасность

- используется UDP 28020; для интернета настройте port forwarding и firewall;
- трафик ENet не шифруется, токен контролирует вход, но не обеспечивает конфиденциальность;
- не передавайте токен через публичные Issues, скриншоты или логи;
- для постоянного сервиса используйте отдельного непривилегированного пользователя и `--token-file`;
- сервер поддерживает 64 участника на уровне протокола, однако клиент alpha показывает только семь удалённых машин, поэтому практический предел — восемь игроков.

## Сборка

Требуются CMake 3.24+, Git, C++20 compiler и доступ к сети для получения ENet по закреплённому commit SHA.

Windows x86_64:

```powershell
.\tools\Build-Ht2mpServer.ps1 -Platform windows-x64
```

Linux x86_64:

```bash
bash tools/build-server.sh
```

Архивы появляются в `dist/server/`. Для проверки без упаковки:

```bash
cmake --preset server-linux-x64
cmake --build --preset build-server-linux-x64 --parallel
ctest --preset test-server-linux-x64
```
