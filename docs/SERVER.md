# Свой сервер HT2MP

Сервер нужен одному из участников: он запускает его и передаёт друзьям адрес и код доступа. Устанавливать игру на компьютер с сервером не требуется. Доступны версии для Windows и Linux x64; текущий клиент рассчитан на сессию до **8 игроков**.

## Windows

1. [Скачайте сервер для Windows](https://github.com/smbdsbrain/HT2MP/releases/download/v0.1.0-alpha.1/HT2MP-server-0.1.0-alpha.1-windows-x86_64.zip) и распакуйте архив в отдельную папку.
2. Откройте `start-server.cmd`. Если брандмауэр Windows запросит доступ к частной сети, разрешите его.
3. В окне появится `token` — код доступа. Передайте его друзьям вместе с адресом сервера.
4. Оставьте окно открытым, пока играете. Для остановки нажмите `Ctrl+C`.

## Linux

[Скачайте сервер для Linux](https://github.com/smbdsbrain/HT2MP/releases/download/v0.1.0-alpha.1/HT2MP-server-0.1.0-alpha.1-linux-x86_64.tar.gz), затем выполните в папке с архивом:

```bash
mkdir HT2MP-server
tar -xzf HT2MP-server-0.1.0-alpha.1-linux-x86_64.tar.gz -C HT2MP-server
cd HT2MP-server
./start-server.sh
```

Скопируйте код `token` из терминала и оставьте сервер работать до конца игры. Для остановки нажмите `Ctrl+C`.

## Подключение друзей

Адрес в лаунчере указывается в формате `<IP-сервера>:28020`:

- На том же компьютере используйте `127.0.0.1:28020`.
- В одной локальной сети друзьям нужен локальный IP компьютера с сервером.
- Через интернет нужен публичный IP. На роутере перенаправьте **UDP-порт 28020** на компьютер с сервером и разрешите этот порт в брандмауэре.

`0.0.0.0:28020` в окне сервера означает, что он принимает подключения через доступные сетевые интерфейсы. Этот адрес не нужно вводить друзьям.

Если провайдер не выдаёт публичный IP, одного перенаправления порта будет недостаточно. Можно запросить публичный IP у провайдера или попробовать общую VPN-сеть; длительная работа HT2MP через VPN ещё недостаточно проверена.

При каждом запуске обычным скриптом создаётся новый токен. Его нужно заново передать игрокам. Не публикуйте токен в открытом доступе: он ограничивает вход на сервер, но не шифрует сетевой трафик.

## Дополнительные настройки

Эти команды нужны для локальных тестов или постоянного сервера. Для обычной игры достаточно скриптов выше.

### Только на своём компьютере

Так сервер будет недоступен другим компьютерам:

```powershell
.\start-server.cmd 127.0.0.1:28020
```

В Linux используйте `./start-server.sh 127.0.0.1:28020`.

### Постоянный токен или вход без кода

Из папки распакованного сервера:

```bash
# Постоянный токен из файла
bin/ht2mp-coordinator --listen 0.0.0.0:28020 \
  --profile steam-8138acee --token-file /etc/ht2mp/token

# Публичный сервер: вход без кода доступа
bin/ht2mp-coordinator --listen 0.0.0.0:28020 \
  --profile steam-8138acee --public
```

Это команды для Linux. В Windows запускайте `bin\ht2mp-coordinator.exe` с теми же параметрами в одной строке и своим путём к файлу токена.

Файл токена должен содержать ровно 32 шестнадцатеричных символа. Ограничьте доступ к нему пользователем, от имени которого работает сервер. Параметры `--public`, `--token` и `--token-file` нельзя сочетать. Без них сервер создаёт временный токен и показывает его один раз при запуске.

Параметры времени и погоды доступны через `bin/ht2mp-coordinator --help`. Инструкция по сборке сервера находится в [руководстве для разработчиков](../CONTRIBUTING.md).
