# Политика безопасности

## Поддерживаемые версии

| Версия | Исправления безопасности |
| --- | --- |
| `0.1.x-alpha` | Да |
| Более ранние сборки | Нет |

## Как сообщить об уязвимости

Не создавайте публичный issue. Откройте вкладку **Security** репозитория и выберите **Report a vulnerability**, чтобы создать приватный отчёт.

Укажите версию HT2MP, операционную систему, минимальные шаги воспроизведения и ожидаемое влияние. Не прикладывайте `king.exe`, игровые библиотеки, сохранения или неочищенные логи. Замените токены, IP-адреса, имена игроков и локальные пути placeholders.

Первое подтверждение отчёта планируется в течение семи дней. Исправление и раскрытие будут согласованы в приватном advisory.

## Важные свойства alpha

- bridge разрешает активный режим только для полного хеша и проверенных сигнатур поддерживаемой игры;
- исходная установка игры не должна изменяться;
- серверный токен не шифрует ENet/UDP-трафик и не должен повторно использоваться как пароль другого сервиса;
- Windows-релиз пока не подписан Authenticode, поэтому проверяйте SHA-256 и GitHub provenance.
